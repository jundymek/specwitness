**The rebase verdict** (`hooks/lib-pr-poll.sh:451-513`, invoked at 669-671, written at 690) is computed **only when an agent was told to rebase and did**; an agent that never owed one has **no key at all, and that passes** — absence is not `unknown`. ### Failure modes (what "wrong" looks like here)

- **Weakening the unconditional clause.** Applying the human rule only when there are no attempts is the exact variant review rejected in Epic 3 as a silent redesign. It would let a probe adjudicate a criterion whose author wrote "no machine may answer this."
- **Adding a third NEEDS_HUMAN trigger** — most temptingly, turning an execution-time uncertainty into a question for a human. Q39 says `error`.
- **Re-implementing `aggregate` or touching the exit table.** Both merged, both correct.
- **A NEEDS_HUMAN report that tells a human nothing.** The failure this story exists to fix, arriving with more fields and no more meaning.
- **Inventing guidance text** when the plan has none. A synthesised sentence in a report is a fact the JSON view does not carry.
- **An unredacted secret in the guidance**, reaching `result.json` and a terminal — the exact hole `deriveCriterionResult` already closes for `expected`/`actual`.
- **An unbounded guidance field** blowing FR-29's bounded-output rule in an agent's context window.
- **A breaking schema change** that stops last week's `result.json` parsing.
- **Transforming anything in `src/report/json.ts`** — two byte sequences that drift.
- **Adding a field to `ContractSpec`**, changing the fingerprint of every frozen contract in existence.
