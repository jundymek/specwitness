Clarifications (detail only, no weakening):

- **⚠️ AC1'S REAL REQUIREMENT IS "BYTE-IDENTICAL", AND IT MUST BE ASSERTED MECHANICALLY, NOT ARGUED.** This is the whole story. **Run the same fixture twice — once with `--explain`, once without — and compare the persisted `RunResult` with the explanation field removed. - **⚠️ THE `explainer` ROLE IS ALREADY DECLARED. ## Dev Notes

### Goal & Context

**This is a story whose entire value proposition is that it changes nothing.**

Every other AI-touching flow in this product produces an artifact that matters: a contract draft a human freezes, a plan that becomes executable. The explainer produces **a sentence somebody reads and may ignore.** It exists because a repair agent handed a bare `expected: 200, actual: 500` starts from zero, and a hypothesis — *"the service returned 500 on every request after the data reset; the migration in the diff drops a column this endpoint reads"* — is a head start.

That is a convenience, and conveniences are where boundaries erode. AD-2 exists because *"AI becoming the source of truth"* is the failure this product is built against, and the first non-negotiable rule in `CLAUDE.md` is **never ask an LLM whether it passes.** An explainer sits closer to that line than anything else in V0: it reads the evidence, forms an opinion about the failure, and prints it beside the verdict. **The only thing keeping it honest is that it is provably inert.**

So the acceptance criterion that matters is not "the explanation is useful." It is **byte-identical with and without `--explain`**, asserted mechanically. Write that test first, and let it fail before it passes.

Two invariants carry the story:

1. **An explainer never touches a verdict.** Not the status, not the aggregation, not the exit code. AD-2, and Q50–Q52.
2. **`--no-ai` still means zero provider calls.** FR-18 and Q66 are the product's determinism guarantee; 4.7 proved them end to end. **You add a provider call to the verify path, so you must prove it is off by default.**

### Failure modes (what "wrong" looks like here)

- **⚠️ An explanation that influences a result.** The failure this story exists to make impossible, and the reason the byte-identical assertion is the headline AC rather than a nicety.
- **An explainer that runs by default.** Breaks FR-18/Q66, spends subscription quota nobody asked for, and makes `--no-ai` a lie.
- **`--no-ai --explain` silently dropping one flag.** People misread flag pairs; refuse or no-op, but say which.
- **An explainer failure failing the run.** The inverse of every other provider call in the product — and a convenience that can break a verification is not a convenience.
- **Re-reading raw evidence to enrich the prompt**, sending a credential off the machine that redaction had already caught. The most likely security defect in this story, and it arrives as helpfulness.
- **An unredacted or unbounded hypothesis** reaching `result.json` and a terminal.
- **A hypothesis that reads like a finding.** "Clearly labeled non-authoritative" is in the AC because an unlabelled hypothesis beside a verdict *becomes* a finding in the reader's mind.
- **Dropping the `providerUsage` record to make the byte test pass** — hiding a subscription cost that FR-15 and Q65 exist to make visible.
- **A second schema gate**, or an adapter that validates. AD-2 names one gate, by path.
- **`report --explain` re-executing anything.** Q52 forbids it.
- **A breaking schema change** that stops last week's `result.json` parsing.

### Security

- **Everything sent to the provider must already be redacted and bounded.** `expected`/`actual` are redacted at derivation; evidence members at capture. **Never re-read a raw file for context.** A prompt is data leaving the process.
- **The hypothesis coming back is untrusted text.** Redact and bound it at capture. **Assert secrets are ABSENT, never that `[REDACTED]` is present** (Epic 3 retro §7 — output containing the marker *with the secret still beside it* survives review in a way a raw leak does not).
- **Never read, copy or persist `~/.claude/`, `~/.codex/` or any credential store** (NFR-1, AD-4, Q59). `tests/unit/doctor/credential-boundary.test.ts` enforces it — keep it green.
